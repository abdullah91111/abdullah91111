# Profile assets

The SVG banner and project cards are original artwork, generated with:

```sh
python scripts/render-assets.py
```

Each graphic has desktop/mobile and light/dark variants. Text alternatives live in the profile README. The SVGs do not load external fonts, scripts, or resources.

Company logos were copied unchanged from `public/company-lorrysa.png`, `public/company-brainyai.jpg`, and `public/company-purecs.jpg` in [my portfolio](https://github.com/abdullah91111/portfolio/tree/05d5bd846258b07b97f9366ac9660827d1087ab9/public). Experience and project descriptions were aligned with the portfolio on October 27, 2026.

The layout takes inspiration from [Brxerq's profile](https://github.com/Brxerq/Brxerq); the artwork and content here are specific to Abdullah Taufiq.

The contribution snake is generated by `.github/workflows/snake.yml` daily, on manual dispatch, and whenever the workflow changes on `main`. It publishes only generated files to the `output` branch, using the repository's automatic `GITHUB_TOKEN`. No personal token or extra secret is needed. GitHub schedules can run later than the configured time.

# Profile assets

The profile uses plain Markdown for the introduction and projects. Its banner is the existing mountain-and-lake artwork from [my portfolio](https://github.com/abdullah91111/portfolio/blob/05d5bd846258b07b97f9366ac9660827d1087ab9/public/banner.webp), copied unchanged as `portfolio-banner.webp`.

The light and dark SVG wrappers reuse that image and reproduce the portfolio's subtle drifting leaves, edge fades, and dark-image brightness/saturation. They contain no JavaScript or external requests. Reduced-motion preferences disable the leaves.

Technology badges use the portfolio's zinc/black/white palette, with logo paths from [Simple Icons 16.36.0](https://github.com/simple-icons/simple-icons/releases/tag/16.36.0). Its CC0 license is included in `SIMPLE-ICONS-LICENSE.md`. Tools without an available icon use a text-only badge. Grouping and outlined badges take inspiration from the user's reference screenshot.

To regenerate the banner wrappers and logo badges:

```sh
python scripts/render-profile.py
```

Badge labels and logo paths live in `scripts/tech-stack.json`.

Company logos were copied unchanged from `public/company-lorrysa.png`, `public/company-brainyai.jpg`, and `public/company-purecs.jpg` in [my portfolio](https://github.com/abdullah91111/portfolio/tree/05d5bd846258b07b97f9366ac9660827d1087ab9/public). Experience and project descriptions were aligned with the portfolio on October 27, 2026.

The contribution snake is generated by `.github/workflows/snake.yml` daily, on manual dispatch, and whenever the workflow changes on `main`. It publishes only generated files to the `output` branch, using the repository's automatic `GITHUB_TOKEN`. No personal token or extra secret is needed. GitHub schedules can run later than the configured time.
